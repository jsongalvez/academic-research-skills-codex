# Literary MT Research

## Start from repository state

1. Locate the Literary-MT-Research repository.
2. Read `AGENTS.md`, `PROJECT_STATE.md`, `ROADMAP.md`, and `docs/SESSION_HANDOFF.md`.
3. Read only specialist documents relevant to the task.
4. Check branch and working tree before editing.
5. Select the highest-value next task already supported by project state. Do not reopen settled questions without new evidence.

If the repository is unavailable, ask for access or files. Do not reconstruct its state from chat memory or guesses.

## Mission

Develop a scalable, local-first system translating modern Chinese, Japanese, and Korean literary works into natural, compelling English. Preserve meaning, authorial style, narrative voice, character identity, relationships, viewpoint, and consistency across long works. Classical Chinese is a separate exploratory track.

Optimize quality-accepted English words per total cost, including inference, human review, correction, and operations. Reader experience outranks benchmark scores.

## Research discipline

- Be model-, architecture-, and training-method agnostic.
- Prefer primary papers, official model cards, dataset documentation, original code, and direct experimental evidence.
- Separate source findings from author interpretations and vendor claims.
- Distinguish independently reproduced results from self-reported results.
- State what evidence establishes and what it does not.
- Preserve contradictions, uncertainty, and negative results.
- For major recommendations state evidence, limitations, assumptions, and a falsifiable validation experiment.
- Do not narrow the language scope because a resource is missing for one language.
- Do not optimize proxy metrics at the expense of fidelity or reader enjoyment.

## Cost and scope

Work on the smallest question that can change a decision. Avoid broad literature reviews when a targeted source check or experiment design is sufficient. Update authoritative records in place; do not create redundant documents.

No inference, training, bulk downloads, paid compute, or expensive experiments without explicit user authorization. No local model dry-run without authorization if it performs inference or meaningful compute.

## Session handoff

Finish each session with:
1. Completed work.
2. New evidence and citations.
3. Decisions changed or unchanged.
4. Unresolved questions and uncertainty.
5. Files/commit changed and checks actually run.
6. One next task.

Use the specialized verification, synthesis, and experiment-design skills when appropriate.
